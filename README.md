# Новгород 1230: город мёртвых

Интерактивная игра по Новгородской первой летописи о голоде 1230–1231 годов. Играть можно в браузере, на компьютере и на телефоне. Проект канала Caves Of Time.

**Играть:** [](https://bergariusdesign.github.io/novgorod-1230-game/)

## О чём игра

В 1230–1231 годах Новгород пережил голод, после которого осталось три общие могилы. В игре вы листаете летописный свиток из десяти страниц:

- заморозьте посевы ползунком и посмотрите, как гибнет урожай;
- принимайте решения за новгородскую семью (глава «Удержать черту»);
- отвечайте на вопросы по записи летописца и узнавайте, что в источнике сказано прямо, а что неизвестно;
- пройдите пожар, перешедший через Волхов, и дождитесь немецких купцов с хлебом.

## Историческая основа

Сюжет опирается на Новгородскую первую летопись. Игра старается не выдавать догадки за факты:

- всё, что говорит летопись, подаётся как запись летописи;
- всё, что придумано для наглядности (например, шкала «расстояние до черты»), подписано как условное или как модель;
- то, чего источник не сообщает (общее число погибших, имена, судьбы отдельных семей), в игре названо неизвестным.

## Как запустить

Игра состоит из одного файла `index.html`. Установка и сборка не нужны.

1. Скачайте репозиторий.
2. Откройте `index.html` в браузере.

## Структура

```
index.html     игра целиком (код, стили, встроенные кадры)
img/           необязательная папка со своими картинками для сцен
README.md
```

## Звук

Звук (ветер, треск огня, щелчки при выборе) включается кнопкой «Звук» в правом верхнем углу. На iPhone и в некоторых браузерах звук запускается только после нажатия на эту кнопку.

## Технологии

HTML, CSS и JavaScript в одном файле, без библиотек. Шрифты подгружаются с Google Fonts. Без интернета игра работает с системными шрифтами.
